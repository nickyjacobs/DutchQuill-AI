# README

Lees eerst de repository (de bestaande README, het package-bestand, de code-indeling), zodat je niets verzint.

## Opbouw (de vijf vragen van GitHub)

1. **Wat is het?** Naam en één of twee zinnen. Eventueel een badge-regel of een screenshot.
2. **Waarom zou je het gebruiken?** Voor wie, welk probleem.
3. **Hoe begin je?** Installatie en een minimaal voorbeeld, in codeblokken die je kunt kopiëren.
4. **Waar vind je hulp?** Documentatie, issues, contact.
5. **Wie onderhoudt het, en onder welke licentie?**

Daarna eventueel: configuratie, uitgebreid gebruik, bijdragen (CONTRIBUTING.md), changelog.

## Let op

- Geen marketingtaal (naadloos, krachtig, baanbrekend, "supercharge").
- Commando's moeten kloppen met de repository. Weet je iets niet zeker, zet dan `[controleren]`.
- Relatieve links naar bestanden in de repo.
- Taal: Engels voor een publieke repository, tenzij de gebruiker of de bestaande README Nederlands is.
